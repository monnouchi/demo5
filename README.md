# Musical Stones

[ゲームで遊ぶ](https://monnouchi.github.io/musical-stones/) · [3曲を試聴する](https://monnouchi.github.io/musical-stones/review/)

音の宝石を聴いて並べ、小さな曲をよみがえらせる音楽パズルです。スマートフォン・PCで遊べ、楽譜の知識は要りません。

## 遊び方

1. 「お手本」で完成した曲を聴きます。
2. 宝石をタップして音の断片を聴き、くぼみに左から並べます。ドラッグのほか、宝石を選んで「はめる」「←」「→」「外す」でも操作できます。
3. 「並びを聴く」で試し、「よみがえらせる」で判定します。3曲は自由に選べます。

音量・消音・停止は画面で調整できます。画面を離れると音は停止します。再読み込みすると配置がリセットされ、音量・消音・選択中の曲は保存されます。詳しい操作ややり直しは「宝石の動かし方・曲のヒント」を開いてください。

## ローカルで遊ぶ

Node.js があれば `npm start` を実行し、[ローカル版](http://127.0.0.1:4187/musical-stones/)を開きます。JavaScript と Web Audio に対応したブラウザーを使ってください。
